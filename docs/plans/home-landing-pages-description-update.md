# Updated Service Description: Landing Pages
## Home Page Services Section

### Current Description
```
Páginas diseñadas para generar contactos, cotizaciones y ventas mediante una experiencia enfocada en conversión.
```

### Issues with Current Description
- Generic and interchangeable with other web agencies
- Focuses only on "conversion" (marketing jargon)
- No mention of target audience (service businesses)
- Doesn't communicate value of trust-building or credibility
- Could apply to e-commerce, SaaS, or any other business type

---

## Proposed New Description

### Spanish (es-MX)
```
Sitios y landing pages para negocios de servicios que generan confianza y convierten visitantes en clientes.
```

**Alternative (slightly longer):**
```
Sitios que presentan tus servicios con claridad, generan confianza desde el primer contacto y convierten visitantes en clientes reales.
```

### English (en-US)
```
Websites and landing pages for service businesses that build trust and turn visitors into clients.
```

**Alternative (slightly longer):**
```
Websites that clearly present your services, build trust from first contact, and turn visitors into qualified leads.
```

---

## Why This Works

1. **Specific audience:** "service businesses" instead of generic "businesses"
2. **Concrete benefits:** "build trust" and "turn visitors into clients" instead of abstract "conversion"
3. **Action-oriented:** Uses strong verbs (present, generate/build, turn) instead of passive descriptions
4. **Aligns with new positioning:** Reflects the homepage landing pages service redesign
5. **Consistent tone:** Matches the style of other service descriptions on the home page (specific, concrete, benefit-focused)

---

Update the service card for "Landing pages" on:
